LUMINARA — a travel poster for a place that does not exist. A pure-Python (standard library only) program renders a 1024×1024 vintage travel poster: floating green isles above a glowing lagoon at golden hour, crowned by a single crystal spire, with a sailboat crossing the sun's glitter path and a thread of light falling from the great isle into the water. The invented place's name is set large across the sky, with one short line of promise beneath it. No real destination, no quotes, no star ratings.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024×1024 PNG, under 1 MiB). Deterministic: repeated runs produce byte-identical output. No third-party packages, no network.
